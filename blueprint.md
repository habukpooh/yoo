# Lotto Number Generator

## Overview
A modern, web-based lottery number generator built with pure HTML, CSS, and JavaScript. It features a clean UI with interactive elements and theme support.

## Features
- **Lotto Number Generation:** Generates 2 sets of 6 unique numbers between 1 and 45.
- **Dynamic Styling:** Numbers are color-coded based on their value ranges.
- **Web Components:** Uses custom `<lotto-display>` elements for encapsulation and reusability.
- **Theme Support:** Dark and Light mode toggle with persistent storage.
- **Responsive Design:** Works across different screen sizes.

## Design
- **Dark Theme (Default):** Deep charcoal backgrounds with vibrant accents.
- **Light Theme:** Clean, soft backgrounds with high-contrast text.
- **Typography:** Uses Roboto for a modern, clean look.
- **Interactivity:** Smooth transitions and hover effects on buttons and number displays.
- **Layout:** Vertical stacking of multiple lotto sets for better readability on various devices.
